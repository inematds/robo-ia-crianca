# Educator’s Kit — “Can the robot hear you?”

A 30-minute lesson for children ages 6 to 12, ready to use at school, in faith formation classes, after-school programs, or at home. No robot, internet access, or AI knowledge needed.

| File | What it is |
|---|---|
| [`imprimir.html`](https://inematds.github.io/robo-ia-crianca/kit-educador/en/imprimir.html) | **Open and print**: an A4 poster with 3 questions, an activity sheet, and 2 parent notes per page |
| [`aula.md`](aula.md) | The lesson plan in 4 parts (opening, string activity, 3 questions, ground rules) |
| [`atividade.md`](atividade.md) | The activity sheet in text form (to adapt) |
| [`bilhete-pais.md`](bilhete-pais.md) | The note in text form, to paste into a planner or WhatsApp group |

## The process, from start to finish

1. 🧠 Read the lesson plan (`aula.md`) — 5 min.
2. 🧠 Print the poster, one activity sheet per child, and the notes (`imprimir.html` → Print).
3. 🧠 Set out a long piece of string.
4. 🧠 Teach the lesson (30 min) and send the note home.
5. 🧠 (optional, ages 10–12) Show the sample report from the [network monitor](https://github.com/inematds/robo-ia-crianca/blob/main/vigia/README.en.md) — it’s made up, so let the class know.
